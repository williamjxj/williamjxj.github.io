wenyan2video · Classical Story to Short Video

wenyan2video 动态架构图集

从古籍原文生成口播稿与分镜，合成配音和字幕，生成场景插图，最后通过 FFmpeg 运镜、混音并输出视频。图集也展示批量任务状态与本地 Web 面板。

当前配置把 9:16 竖版比例保留为配置项但权重设为 0，因此批量变体选择 16:9，成片输出为 1920×1080。任务状态为 success 的故事会跳过；单集失败记入状态后，批量 runner 会继续处理后续故事。

实现依据： 项目说明 单集主控 变体引擎 FFmpeg 合成 Web 面板服务

每张图内可使用追踪动画、引导章节和节点探索；标签支持鼠标、方向键、Home 与 End 键切换。
